# Store Compliance Checklist

## Permissions and Privacy

- Document notification usage and purpose.
- Provide privacy policy URL inside app and store listing.
- Disclose webview data handling in Data Safety/App Privacy forms.

## Release Metadata

- App name, subtitle, description, keywords.
- Screenshots for all required device classes.
- Support and contact URLs.

## Operational Controls

- Maintenance mode switch available.
- Rollback strategy documented.
- Crash monitoring enabled before release.
