# DressFair QA Matrix

## Core Journeys

- Browse catalog in WebView
- Open product details
- Add to cart
- Start checkout
- Payment redirect and return
- Order success page
- Notification tap to product/order page

## Reliability Cases

- Offline launch
- Network drop during checkout
- Session expiry mid-flow
- Web page load failure and retry
- Unknown deep-link payload

## Device Coverage

- Android: low-end, mid-tier, flagship
- iOS: 2 latest major versions
- Orientation lock and safe-area verification
